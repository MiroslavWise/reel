# Как прокачать «Reel» 🎡

Сейчас у тебя классный минимализм, но он выглядит скорее как инструмент, чем как игра. Судя по скриншотам, самые «скучные» места: плоский белый фон, чёрно-белые кнопки, простая синяя полоска-указатель и отсутствие реакции на выпадение победителя. Вот что можно сделать и готовые промпты.

---

## Идеи по частям интерфейса

🎨 Атмосфера
- Мягкий анимированный градиентный фон (пастельные фиолетово-розово-голубые переливы) или тёмная неоновая тема
- Заголовок с градиентной заливкой текста
- Плавные появления карточек (staggered fade-in)

🎰 Сам барабан (главное!)
- У каждого участника — свой яркий цвет карточки (тот же цвет, что точка в списке)
- Лёгкий градиент + глянцевый блик на карточках — эффект слот-машины
- 3D-глубина: карточки у краёв экрана меньше и прозрачнее
- Motion blur на скорости, при замедлении — чёткость
- Вместо синей полоски — стрелка/скобки с неоновым свечением
- Пружинная остановка с отскоком победителя

🎉 Победа
- Конфетти (canvas-confetti)
- Модалка с именем победителя: градиентная рамка, spring-анимация, эмодзи
- Тикающий звук при прокрутке + фанфары при победе (с кнопкой mute)

---

## Готовые промпты для ИИ-агента

Промпт 1 — общий редизайн:
Переделай визуальный стиль приложения, НЕ меняя логику и структуру. 
Сейчас дизайн чёрно-белый и плоский, сделай его праздничным:
- Фон: мягкий анимированный градиент (пастельные фиолетовый/розовый/голубой), 
  плавное переливание цветов, CSS animation 15-20s
- Заголовок "Reel": крупный шрифт Unbounded или Rubik (кириллица), 
  градиентная заливка через background-clip: text
- Кнопки "Создать"/"Запустить": градиент фиолетовый→розовый, белый текст, 
  border-radius 16px, лёгкое свечение box-shadow, при нажатии scale(0.97)
- Карточки участников: белый фон, стеклянный эффект backdrop-filter: blur, 
  слева цветная полоска-акцент
- Плавное появление элементов: staggered fade-in-up, 300ms
Вынеси палитру в CSS-переменные. Функциональность не трогай.

Промпт 2 — прокачка барабана:
Улучши горизонтальный барабан (reel), где карточки с именами прокручиваются 
мимо центрального указателя:
1. Каждому участнику — свой яркий цвет (генерируй через HSL с золотым углом 
   ~137°, чтобы цвета различались). На карточке лёгкий вертикальный градиент 
   для объёма и глянцевый блик сверху
2. Эффект 3D: карточки по краям экрана scale(0.85) и opacity 0.6, 
   в центре — полный размер (как у wheelofnames)
3. Указатель по центру: вместо синей полоски — стильные скобки/стрелки 
   с неоновым свечением и лёгкой пульсацией
4. При быстрой прокрутке — motion blur (blur 2-4px пропорционально скорости), 
   при замедлении — чётко
5. Остановка: spring-анимация, карточка победителя слегка отскакивает, 
   затем подсвечивается градиентной рамкой, scale 1.05, остальные тускнеют
Используй framer-motion. Логику случайного выбора не менять.

Промпт 3 — празднование:
Добавь celebration-эффекты при выпадении победителя:
1. Конфетти через canvas-confetti: залп с двух сторон по центру, 
   цвета брать из палитры карточек
2. Модалка победителя: карточка с анимированной градиентной рамкой 
   (conic-gradient + rotate), крупное имя со spring-появлением, эмодзи 🎉, 
   кнопки "Крутить ещё" и "Закрыть". Появление: scale 0.9→1 + fade

Промпт 4 — тёмная неоновая тема (альтернатива):
Сделай тёмную тему в стиле аркадной игры:
- Фон #0a0a12 с размытыми цветными пятнами (blurred radial gradients, 
  розовый/синий/фиолетовый), плавно плавающими
- Карточки тёмные с неоновой рамкой своего цвета: box-shadow: 0 0 20px color
- Указатель — неоновая стрелка с glow
- Кнопки с пульсирующим неоновым свечением
- Переключатель light/dark в шапке, сохранение в localStorage

## Полезные мелочи

- Библиотеки: framer-motion (анимации), canvas-confetti (конфетти)
- Шрифты с кириллицей: Unbounded, Rubik, Nunito, Comfortaa (Google Fonts)
- Связка цветов: присваивай цвет участнику один раз и используй его везде — точка в списке, карточка в барабане, конфетти. Это делает дизайн целостным
- Производительность: на мобильном Safari не злоупотребляй blur и постоянными box-shadow анимациями — анимируй только transform и opacity
- Доступность: добавь @media (prefers-reduced-motion: reduce) — отключай конфетти и blur

Совет по применению: не вставляй все промпты сразу — давай агенту по одному, после каждого проверяй, что выбор победителя всё ещё работает корректно (визуальные агенты любят ломать логику при редизайне). Начни с промпта 2 — барабан даст максимальный вау-эффект.
